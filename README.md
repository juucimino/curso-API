# API de cursos
API para gerenciamento de **professores** e **cursos**

## Tecnologias 
-Javascript
-Node JS
-Mysql
-express

## Endpoints
- 'POST / professores' - Cria um professor
- 'GET / professores' - Lista professores
- 'POST / cursos' - Cria um curso
- 'GET / cursos' - Lista de cursos
- 'DELETE / cursos/:id' Deleta um curso por id
